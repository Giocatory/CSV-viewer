# 📊 CSV/XLSX Viewer — Парсер структурированных данных

![WPF Application](https://via.placeholder.com/800x400/2c3e50/ffffff?text=CSV/XLSX+Viewer+Interface)  
*Интерфейс приложения с поддержкой редактирования, фильтрации и визуальной индикацией изменений*

## 🎓 Учебный проект для студентов первых курсов по системному программированию

Этот проект создан специально **для студентов первых курсов**, изучающих системное программирование, чтобы продемонстрировать разницу между поверхностным подходом к обработке данных и инженерным решением реальных задач. Проект идеально подходит для понимания:

- ✅ Как работают настоящие парсеры (не просто `Split(',')`)
- ✅ Почему важно учитывать крайние случаи при работе с данными
- ✅ Как проектировать архитектуру приложения (MVVM)
- ✅ Как отслеживать изменения в данных и управлять состоянием
- ✅ Как работать с потоками (Stream) для обработки больших файлов

---

## 📌 Суть проекта: Парсинг как инженерная задача

Большинство начинающих программистов решают задачу парсинга CSV одной строкой кода:
```csharp
string[] values = line.Split(',');
```

**Но реальные CSV-файлы содержат сложные случаи:**
- Поля в кавычках: `"Иванов, Петр"`
- Экранированные кавычки: `"ООО ""Ромашка"""`
- Переносы строк внутри полей
- Разные разделители (`,`, `;`, `TAB`, `|`)
- Пустые и частично заполненные строки

Этот проект показывает **инженерный подход** — реализацию конечного автомата для корректной обработки всех случаев, что критически важно в production-системах.

## ✨ Функциональные возможности

### 📥 Загрузка данных
- Поддержка форматов **CSV** и **XLSX** (Excel)
- Автоматическое определение формата файла
- Корректная обработка кавычек, экранирования и переносов строк
- Выбор разделителя для CSV (`,`, `;`, `TAB`, `|`)

### 🔍 Работа с данными
- **Редактирование ячеек** в режиме реального времени
- **Визуальная индикация изменений** (изменённые ячейки подсвечиваются жёлтым)
- **Сортировка** по любому столбцу (кликом по заголовку)
- **Фильтрация** по всем столбцам одновременно

### 💾 Управление изменениями
- Кнопка **«Сохранить изменения»** активируется автоматически при редактировании

- Сохранение в исходный формат (CSV → CSV, XLSX → XLSX)
- Экспорт в **JSON** для интеграции с другими системами

### 📊 Интерфейс
- Чистый и интуитивно понятный дизайн на WPF
- Адаптивная таблица с автоматической шириной столбцов
- Статусная строка с информацией о количестве строк/столбцов
- Подсказки (tooltips) для всех элементов управления

## 🔬 Инженерный парсинг vs Наивный подход

### ❌ Наивный подход (типичная ошибка новичков)
```csharp
// НЕ РАБОТАЕТ с реальными данными!
string[] values = line.Split(',');
```

**Проблемы:**
- `"Иванов, Петр"` → разобьётся на 2 поля вместо 1
- `"ООО ""Ромашка"""` → кавычки обработаются некорректно
- Переносы строк внутри полей сломают структуру

### ✅ Инженерный подход (реализован в проекте)
```csharp
// CsvParser.cs — конечный автомат с состояниями
while (reader.Peek() >= 0)
{
    char c = (char)reader.Read();

    if (inQuotes) // Состояние "внутри кавычек"
    {
        if (c == '"' && prevChar == '"') // Экранированная кавычка
        {
            currentField.Append('"');
            prevChar = '\0';
            continue;
        }
        else if (c == '"') // Закрывающая кавычка
        {
            inQuotes = false;
            continue;
        }
        currentField.Append(c);
    }
    else // Состояние "вне кавычек"
    {
        if (c == '"') inQuotes = true;
        else if (c == delimiter) { /* добавить поле */ }
        else if (c == '\r' || c == '\n') { /* новая строка */ }
        else currentField.Append(c);
    }
    prevChar = c;
}
```

**Преимущества:**
- Корректная обработка всех крайних случаев
- Поддержка переносов строк внутри полей
- Экранирование кавычек (`""` → `"`)
- Работа с большими файлами через потоки (без загрузки всего файла в память)

## 📚 Учебная ценность для студентов

### Что изучают студенты на этом проекте:

| Тема | Где реализовано | Практическая польза |
|------|-----------------|---------------------|
| **Конечные автоматы** | `CsvParser.cs` | Понимание как работают настоящие парсеры (не регулярки!) |
| **Работа с потоками** | `Stream` в парсерах | Обработка больших файлов без переполнения памяти |
| **Отслеживание изменений** | `EditableCell/Row` | Реализация Undo/Redo, dirty flags |
| **MVVM архитектура** | `MainViewModel.cs` | Разделение логики и UI для поддержки |
| **Привязки данных** | XAML + `INotifyPropertyChanged` | Автоматическое обновление интерфейса |
| **Обработка ошибок** | `try/catch` в командах | Надёжность при работе с внешними файлами |
| **Тестирование крайних случаев** | Разные форматы CSV | Подготовка к работе с "грязными" реальными данными |

### Почему это важно для системного программирования:
> Системное программирование — это не только работа с низкоуровневыми API, но и **понимание как корректно обрабатывать данные**. Ошибка в парсере может привести к:
> - Утечкам данных (неправильная интерпретация полей)
> - Падению приложения (необработанные исключения)
> - Потере информации (обрезка данных при экранировании)
> 
> Этот проект учит **думать как инженер**, а не как скриптовый программист.
